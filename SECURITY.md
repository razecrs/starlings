# Security

Please report security issues privately instead of opening a public issue.

Use GitHub's private vulnerability reporting for this repository. Include the affected version or commit, a minimal reproduction, and the impact you observed. Discord tokens, database credentials, user data, and live guild IDs do not belong in the report; replace them with test values.

The supported line is the latest tagged release. Security fixes may be applied only there when older releases depend on retired Discord protocols or unsupported Go versions.
